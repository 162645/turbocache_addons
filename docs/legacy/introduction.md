# TurboCache 项目介绍

TurboCache 是一个基于 Go 语言开发的高性能、分布式二级缓存系统。它在经典的 `geecache` 基础上进行了深度改进，引入了现代分布式系统的核心特性，旨在提供企业级的缓存解决方案。

## 1. 核心技术栈

项目采用了当前后端开发的主流技术栈，展现了对高性能并发编程和云原生架构的深入理解：

- **核心语言**: Go 1.24+ (充分利用其高性能并发特性)
- **通信协议**: gRPC + Protobuf (实现节点间高效、低延迟的数据交互)
- **服务发现**: etcd (支持动态节点注册、发现与集群健康检查)
- **网络传输**: HTTP/1.1 & gRPC 双协议支持
- **监控与可观测性**: Prometheus (指标收集) + Grafana (可视化仪表盘)
- **容器化与编排**: Docker, Kubernetes, Helm (完整的云原生部署方案)

## 2. 核心架构设计

TurboCache 采用 **L1 本地缓存 + L2 分布式缓存** 的多级设计：

- **L1 本地缓存**: 基于内存的高效存储，利用分片锁和 LRU/LFU/ARC 淘汰策略。
- **L2 分布式缓存**: 基于一致性哈希（Consistent Hashing）将数据分布在集群节点中，支持多副本冗余。
- **动态扩容**: 当新节点加入时，基于 etcd 的发现机制会自动触发一致性哈希环的更新，实现无缝扩容。

## 3. 防护机制 (关键特色)

为了应对生产环境中的极端情况，TurboCache 集成了以下高级防护模块：

- **布隆过滤器 (Bloom Filter)**: 有效拦截不存在的键，防止 **缓存穿透**。
- **SingleFlight**: 合并针对同一键的并发请求，确保只有一个请求穿透到后端源，防止 **缓存击穿**。
- **熔断器 (Circuit Breaker)**: 当后端负载过高或故障时自动切断，保护系统不被冲垮，防止 **缓存雪崩**。
- **负缓存 (Negative Cache)**: 缓存不存在的查询结果，进一步减轻后端负担。
- **热点保护**: 识别并自动缓存高频访问的“热点”数据。

## 4. 项目成果

在基准测试（Benchmark）环境下，TurboCache 表现卓越：

- **吞吐量**: 单节点可轻松突破 **100,000+ QPS**。
- **低延迟**: P99 延迟稳定在 **3ms 以下**。
- **高可用**: 成功通过多种 **混沌测试 (Chaos Testing)** 场景，包括单点故障、网络分区等，系统具备强大的韧性。
- **易运维**: 内置 **Web Admin UI**，可实时监控缓存命中率、QPS、集群状态等核心指标。
